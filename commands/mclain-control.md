# McLain Control

Source skill: `skills/mclain-project-command-center/SKILL.md`

Use the `mclain-project-command-center` skill.

For the requested scope:
1. Reconcile current state from the strongest available sources.
2. Mark the state as SHIP, VERIFY, BUILD, UNBLOCK, or PARK.
3. Show the latest proof.
4. Identify the primary source of truth.
5. Surface blockers and hidden fragility.
6. Return exactly three prioritized executable actions unless fewer are genuinely required.
7. Identify at least one reusable asset or automation opportunity when one exists.
8. State the acceptance criterion that closes the next milestone.

Do not ask the operator to repeat information that is already available.
